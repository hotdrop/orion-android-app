# ORION Design Document

- ステータス: 初期UI実装段階
- 最終更新日: 2026-08-01
- プロダクト要件の正本: [`README.md`](../README.md)

## 1. アプリの目的

ORIONは、技術情報と読書メモを管理する個人用Androidアプリです。
近未来のAI研究施設にある司令システムをテーマにし、「実用性よりもワクワクを優先する」という考え方で、UI、アニメーション、サウンド、触覚を設計します。
ORIONの機能は次の2つです。

- Incoming Intelligence
- Knowledge Archive

ORIONへのアクセスは、起動時とバックグラウンドからの復帰時に端末認証で保護します。

## 2. Secure Access

- 起動時とバックグラウンドからの復帰時に、生体認証または端末のPIN・パターン・パスワードを求めます。
- 認証前は通常画面を操作できない全画面のセキュアブートを表示し、認証成功後は解除演出を経て通常画面へ移行します。
- 認証をキャンセルした場合はロックを維持し、再試行できます。
- 端末に認証情報が設定されていない場合は、端末のセキュリティ設定へ移動できます。
- 端末のアニメーションが無効な場合も、演出待ちなしで同じ認証操作を完了できます。

## 3. Incoming Intelligence

今週収集した技術レポートを、Google Driveから取得して一覧表示する機能です。アプリの通常起動時には、この画面を最初に表示します。

### 表示する情報

- Googleドキュメントのタイトル
- Google Drive上の最終更新日時
- 設定したフォルダからの相対パス

タイトルが長い場合は最大2行、パスが長い場合は最大1行で省略表示します。Googleドキュメントの本文や概要は表示しません。

### 操作

- SettingsでGoogleアカウントと対象フォルダを設定します。
- ORIONはIncoming Intelligence画面の`SYNC`操作を実行したときだけ、対象フォルダとそのサブフォルダ内のGoogleドキュメントを取得します。起動時やバックグラウンドでは自動取得しません。
  - 取得したタイトル、更新日、パスはRoomに保存します。
  - 新しいドキュメントと過去のドキュメントは目視でわかるようにUIで表現します。
- 同期が途中で失敗した場合はRoomの既存一覧を変更せず、対象フォルダ全体を取得できた場合だけキャッシュを更新します。
- 一覧の項目をタップすると、対象のGoogleドキュメントをGoogleドキュメントアプリまたはブラウザで開きます。
- ORION内にGoogleドキュメントを表示する画面は作りません。

### 画面の状態

- Drive未設定
- ドキュメント一覧
- 対象ドキュメントなし
- 同期中
- オフライン
- 認証または同期エラー

オフラインや同期失敗時も、最後に取得できた一覧は表示し続けます。

## 4. Knowledge Archive

最近読んだ記事や書籍を記録する機能です。

### 保存する情報

- タイトル
- URL
- メモ

### 操作

- 記録の追加、編集、削除を行えます。
- 一覧の`NEW`操作から専用の新規作成画面を開きます。
- 一覧の記録または`EDIT`操作から専用の編集画面を開きます。
- 一覧の`OPEN LINK`操作から、対応アプリまたはブラウザでURLを開きます。
- 保存に成功すると一覧へ戻ります。保存に失敗した場合は入力内容を維持して再試行できます。
- ソフトキーボード表示中も編集内容をスクロールでき、フォーカス中の入力欄を表示領域内で操作できます。
- 入力途中で戻る場合は変更の破棄を確認します。
- 削除は編集画面から行い、実行前に確認します。
- データは端末内へ保存し、Google Driveとは同期しません。

### 入力条件と表示状態

- タイトルとHTTPまたはHTTPSのURLは必須です。メモは任意です。
- 記録は更新日時が新しい順に表示し、同じURLの記録も個別に保存できます。
- 一覧には読み込み中、記録なし、記録一覧、読込エラー、URL起動エラーを表示します。
- 編集画面には読込中、未保存変更、入力エラー、保存中、保存エラー、削除中、削除エラーを表示します。

## 5. 画面構成

- Incoming Intelligenceを通常起動画面にします。
- Incoming IntelligenceとKnowledge Archiveは下部ナビゲーションで切り替えます。
- 共通ヘッダーからSettingsを開けるようにします。
- SettingsではGoogleアカウント、Driveフォルダ、サウンド、触覚、演出軽減を設定します。
- 最初は縦持ちスマートフォン向けの1カラムUIを基準にします。

### Settings

- Google PickerでGoogleアカウントと対象フォルダを選択し、フォルダIDと表示名をRoomへ保存します。
- 対象フォルダは明示的に解除または再選択できます。解除しても取得済みキャッシュは破棄しません。
- フォルダ選択中、接続完了、設定解除、読込・認証エラーを画面上で確認できます。
- サウンド、触覚、演出軽減は今後実装します。

### 現在の実装状態

- 起動時とバックグラウンド復帰時の端末認証、セキュアブート、解除演出を実装済みです。
- 共通ヘッダー、下部ナビゲーション、Navigation ComposeによるSettingsを含む画面遷移を実装済みです。
- 通常起動時はIncoming Intelligenceを選択し、画面を再生成しても選択中のタブを維持します。
- Incoming Intelligenceでは、Google Drive認可、手動同期、サブフォルダ走査、Roomキャッシュ、外部アプリでの文書表示と、Drive未設定、一覧、対象なし、同期中、オフライン、同期エラーの画面状態を実装済みです。
- Knowledge Archiveでは、Roomを使用した一覧、追加、編集、削除と外部アプリでのURL表示を実装済みです。
- Knowledge Archiveの追加・編集画面では下部ナビゲーションを隠し、共通ヘッダーのRETURN操作とシステムの戻る操作で同じ破棄確認を行います。
- SettingsではGoogle PickerによるDriveフォルダ選択、Roomへの保存、接続解除を実装済みです。その他の設定項目は未実装です。
- ApplicationスコープのRoom、Repository、Google Driveデータソースと、各画面のViewModelはDagger Hiltで生成・注入します。
- 各主要画面と共通UIは独立してPreviewでき、画面は外部から状態と操作を受け取る構成にします。

## 6. UIの世界観

- 深い紺と黒に近い背景を使用します。
- シアンを主要な操作と正常状態に使用します。
- アンバーを注意やオフライン、赤を重大なエラーに使用します。
- システムラベルは英語、タイトルやメモなどの内容は日本語で表示します。
- HUD、ホログラム、ターミナル、Mission Controlを意識したパネルと演出を使用します。
- 発光やアニメーションを使いながら、文字の読みやすさと操作可能性を維持します。
- 起動、画面表示、項目タップ、同期結果に短いモーション、サウンド、触覚を付けます。
- サウンド、触覚、強い演出はSettingsから無効化できるようにします。
- 画面全体を常時再描画する重い演出を避け、60FPSを維持します。

## 7. 対象外

- Googleドキュメント本文の取得、解析、保存、アプリ内表示
- Incoming Intelligenceのタイトルや概要のユーザー編集
- Knowledge ArchiveとIncoming Intelligenceの自動関連付け
- 複数ユーザー間の共有や共同編集
